# viLilt 🎙️

**Talk. Listen. Nothing else.**

viLilt is a 100% on-device neural voice and text AI companion built for Apple Silicon (iOS 17.0+). Designed as the pure conversational sister app to **viLoom**, viLilt strips away all agent complexity, tool calling, and action execution to provide an effortless, distraction-free conversational space.

---

## Key Features

- **Hands-Free Ambient Voice Call Mode**: Continuous bidirectional natural dialogue with dynamic audio waveform and breathing chromatic resonance visualizer.
- **Distraction-Free Text Stream**: Fast, minimal conversational chat with interactive keyboard dismissal and per-message audio playback.
- **5 Companion Personas**: Empathetic Friend, Intellectual Mentor, Language Practice Partner, Creative Spark, and Zen Mindfulness.
- **100% On-Device & Zero-Cost**: 100% local Apple Silicon Neural Engine execution, zero cloud servers, zero telemetry, zero subscription paywalls.
- **Multi-Lingual**: Fluent across English, Chinese, Japanese, Spanish, French, German, and 29+ localized languages.
